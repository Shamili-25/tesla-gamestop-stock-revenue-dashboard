# Tesla and GameStop: Stock Price vs Revenue Dashboard

Final assignment for the IBM Data Science course.

## What this project does
- Extracts Tesla (TSLA) and GameStop (GME) stock data with yfinance
- Scrapes quarterly revenue data with requests and BeautifulSoup
- Cleans the revenue data with pandas
- Builds dashboards comparing stock price against revenue

## Files
- `Revenue_Data_and_Building_a_Dashboard.ipynb`: the full notebook with code and outputs

## Tools
Python, pandas, yfinance, requests, BeautifulSoup, Matplotlib
